# Changelog

## 1.0 – 2026-10-12
- First release: contacts in the style of the leather-bound address book of OS X 10.8, working with the real system contacts (Contacts.framework)
- Three views: groups · list · card (⌘1), list · card (⌘2), card only (⌘3)
- View, create, edit, delete; search; groups and smart groups; drag and drop into groups
- vCard import and export, sharing, printing
- Settings (⌘,): sorting/display and custom app icon (PNG, exactly 256 × 256 pixels)
- Repository unified with RetroNotes, RetroCal and RetroReminder: GPL-3.0, English documentation, common layout
